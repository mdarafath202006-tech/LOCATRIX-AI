END-TO-END PROJECT FLOW


01
Estimate on the phone
Use inertial sensors and pedestrian motion estimation; AI-assisted fusion is a planned component.


02
Bluetooth to field device
Send a compact position packet to the user's paired LOCATRIX hardware.


03
LoRa to the gateway
Relay packet over long-range radio to a reachable hub with internet access.


04
Cloud + web console
Gateway uploads reports so authorized admins can view last known estimates and trails.




LOCATRIX-AI software-side dashboard prototype. All people, coordinates, packet counts, confidence values, and gateway states displayed here are illustrative demo data. This page does not access real mobile sensors, receive Bluetooth/LoRa messages, locate a real person, or upload to a cloud service. Production deployment requires the Android sensor application, validated positioning algorithms, paired hardware, gateway software, authenticated cloud APIs, access controls, and field testing.
